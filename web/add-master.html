Adding Master Servers

This page is for server owners: registering your own server with more masters. Just want your in-game "Internet" server browser to show servers again? See fixing the in-game browser instead — that's a client-side fix on your own PC and doesn't need any of this.

RTCW/ET-engine servers report themselves to "master" servers, which is how tools like this one (and in-game server browsers) find them. The official id Software master (wolfmaster.idsoftware.com) has been unreliable, so registering with more than one master keeps your server discoverable even when any single one is down — see current live status of each master.

Add this to your server config

Paste this into your server config (e.g. server.cfg) to register with every master worth registering with right now: the official one (in case it comes back), the iortcw project's own master, the two community masters we found still active while the official one is down, and this project's own master last. 

set sv_master1 "wolfmaster.idsoftware.com"
set sv_master2 "master.iortcw.org"
set sv_master3 "etmaster.net"
set sv_master4 "dpmaster.deathmask.net"
set sv_master5 "wolfmaster.s4ndmod.com"
Why these four
MasterWhy
master.iortcw.org Only pre-set for servers actually running the iortcw engine — most RTCW/ET servers aren't, so this is a master you need to add yourself, not one already covering you. Alive right now.
etmaster.net Community-run replacement for the unreliable official ET master. Currently the largest source of active ET servers we've found.
dpmaster.deathmask.net Long-running generic idTech3 master, widely used by RTCW servers.
wolfmaster.s4ndmod.com This project's own master — adding your server here is what makes it show up on the list itself.

Check current status of all of these (including the official one, in case it ever comes back).

Only sv_master1 has a default that applies broadly (the official master above). sv_master2's master.iortcw.org default is iortcw-specific — if you're not running iortcw, it's not covering you, so slots 2–5 are effectively all "free." The config above sets all five explicitly anyway, so nothing depends on a default you can't see just by reading your own config file.
