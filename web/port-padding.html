Port Padding

A server mirroring itself across a few genuinely different IPs is fine — that's shown on the main list as an ordinary "also broadcasting as" note. What's listed here is different: a single server broadcasting itself from many ports on the same IP, almost always via a UDP proxy, purely to inflate how many times it appears. These are still collapsed to one entry and still served to clients querying this master — nothing here is dropped, this page exists so the padding is visible rather than silently absorbed.
