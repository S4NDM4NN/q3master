Port Padding

A server mirroring itself across a few genuinely different IPs is fine — that's shown on the main list as an ordinary "also broadcasting as" note. What's listed here is different: one detected duplicate ("cloned server") broadcasting itself from many ports on one of its own IPs, almost always via a UDP proxy, purely to inflate how many times it appears. One row per detected clone, matching the one card it's shown as on the main list, broken down by every IP its own addresses actually cluster on — not just whichever one happens to be its "primary." These are still collapsed to one entry and still served to clients querying this master — nothing here is dropped, this page exists so the padding is visible rather than silently absorbed.
