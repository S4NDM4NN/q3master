Port Padding

A server mirroring itself across a few genuinely different IPs is fine — that's shown on the main list as an ordinary "also broadcasting as" note. What's listed here is different: many ports on the same IP that clone detection has linked together, almost always via a UDP proxy, purely to inflate how many times it appears. Every address on an IP counts here, not just ones that happen to match whichever address clone detection picked as that group's "primary" — a busy padding operation can span more than one detected group, and all of them are combined into one row per IP below. These are still collapsed to one entry each and still served to clients querying this master — nothing here is dropped, this page exists so the padding is visible rather than silently absorbed.
