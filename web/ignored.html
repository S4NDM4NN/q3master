Ignored Hosts

This is a short, manually-curated list for hosts doing something worse than ordinary list-padding — those get a full, permanent block: every port on the IP is excluded from the server list and network totals, and it's named here. Simply registering the same server under several ports or addresses to inflate your apparent presence isn't treated as a ban — the list detects that automatically and just shows the server once, with the other addresses it's also broadcasting from noted as "also broadcasting as" on its entry.
